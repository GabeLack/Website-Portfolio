Homebrewed Dungeons & Dragons Setting

Project Link

I have a very long attachment to Dungeons & Dragons, first as a viewer, then a player, then someone to run the game myself in my own world setting. It's a project that I worked towards off & on for a few years when the inspiration hit me to write further elements of the setting. I primarily made it as a very long flow chart blocking out the key events in the 7 ages, then moved to more specific notes about the present written in Obsidian with its far more optimal add-ons for streamlining world-building. The attached PDF is the document for onboarding players into a campaign, meant to introduce the setting and inspire the player into character ideas if they aren't entering with one preconceived.
